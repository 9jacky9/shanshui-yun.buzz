隐私政策

一、核心承诺：严格执行零用户活动日志保留政策（Zero-Log Policy）

山水云将用户的数字隐私视为立身之本。我们在此明确且郑重地声明：山水云实行严格的零用户活动日志策略（Zero User Activity Logs Retained）。我们的系统从不监控、不记录、不存储、也不向任何第三方共享您的任何网络活动轨迹。

具体而言，我们在任何时候均绝对不会保留以下信息：

  • 您访问过的任何目标网站域名、URL 路径或明文/加密传输内容；
  • 您的原始连接源 IP 地址以及分配给您的落地节点会话 IP 映射记录；
  • 您在隧道内发起的任何 DNS 域名解析查询记录；
  • 每次连接的具体建立时间戳、断开时间戳或历史会话元数据。

二、纯 RAM 无盘内存节点架构保障

为了从物理工程层面落实“零日志”承诺，山水云全球 68 个转发与落地节点全部运行于定制的纯内存无盘操作系统（RAM-Disk Architecture）之上，服务器完全剥离了本地持久化日志存储写入模块，任何瞬时转发状态均在数据包离开网卡后立即销毁。

三、最小化账户必要信息说明

为完成账户鉴权与流量额度扣减，控制台数据库仅保存经高强度单向哈希加盐处理的登录邮箱标识以及当月累计已用流量字节总数（仅统计总字节数，不包含任何流向详情）。您可以随时在控制台中一键注销并彻底清除账户数据。
